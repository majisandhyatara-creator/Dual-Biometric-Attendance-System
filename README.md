# Intelligent AI Attendance System
An advanced, dual-biometric attendance management system utilizing artificial intelligence to authenticate students via face and voice recognition. Built with a Streamlit web application and a Flask-based landing page, this project modernizes classroom attendance tracking through automated machine learning pipelines.

# Key Features
-Dual-Biometric Authentication: Integrates both Face Recognition and Voice Recognition ML pipelines for secure student authentication.   
-Real-Time Attendance Prediction: Captures and processes live attendance data using WebCam image analysis and voice inputs.   
-Dedicated User Dashboards:
     -Teacher Portal: Features secure authentication, a dashboard with tabs, and tools to manage subjects and view attendance records.  
     -Student Portal: Allows quick subject enrollment using QR codes and secure access to attendance status.  
-Responsive Landing Page: A mobile-responsive introductory site built with Flask, featuring hero, journey, and tech-stack sections, deployed seamlessly via Vercel.   
-Cloud Deployment: The core application is packaged and deployed using Streamlit for an interactive, stateful user experience.   

# Tech Stack
-Frontend & Core App: Streamlit   
-Landing Page: Flask, HTML/CSS   
-Machine Learning: Python (Face & Voice Recognition Pipelines)   
-Database: Configured with custom database functions for stateful data management   
-Deployment: Streamlit Cloud (App) & Vercel (Landing Page)
